# V1 Limitations

- Not a full Word replacement.
- DOCX import is simplified.
- Complex Word layout may not be preserved.
- Headers and footers are unsupported in V1 export/import.
- Footnotes and endnotes are unsupported.
- Track changes and comments are unsupported.
- Real pagination is unsupported.
- Collaborative editing is unsupported.
- Advanced docxtpl table loops require a separate implementation.
- Gotenberg must be configured separately for PDF preview.
- Auth/RBAC is a stub and must be replaced by real ERP permissions.
